# BROWSIQ — New Hybrid Browser Prototype

## Run
1. Download and extract `BROWSIQ_New_Prototype.zip`.
2. Open `index.html` in Chrome or Edge.
3. Search using the main box or choose one of the suggested tasks.

## Interactive features
- Browser-inspired tabs, address bar, bookmarks and navigation controls
- Clean AI-first new-tab homepage; no visible domain/category menu
- Natural-language search demo for Education, Healthcare, Jobs and Shopping
- Answer summary with confidence labels and links to official/reference sources
- Follow-up search, browser-style search history controls
- Voice input (supported browsers) and read-aloud
- Add/remove reminders saved in local browser storage
- Responsive layout

## Prototype limitations
This is a front-end semi-working prototype. The answers are curated demo responses, not generated by a connected LLM. It does not crawl or open arbitrary websites inside the app, fetch live KEA cutoffs/job listings/product prices, or perform Bhashini translation. The source links open the referenced websites in a new tab. The Verified/Likely/Unverified labels are demo UI examples, not live evidence verification.
